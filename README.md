CAS(Computer Algebra System)의 차이를 관찰할 수 있는 예시를 발견했습니다.

f(x)=(x-1)^((x-2)^(x-3))
이란 함수에서 x의 값의 범위가 1≤x<2일 때 재밌는 현상을 볼 수 있습니다.

이 현상을 우연히 발견하였으며, 단지 수학에 관심이 있는 평범한 고등학생으로서 이를 더 알아보고 싶어서 작성해봅니다.

I have found an example where we can observe differences in the Computer Algebra System (CAS).
